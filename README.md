# Palamner Palace — Full MERN Stack Social-Commerce Marketplace

> Discover products through short-form video Reels. Shop instantly in-stream.

## 📌 Product Vision
Palamner Palace is a full-stack social-commerce marketplace built on the **MERN Stack** (MongoDB, Express.js, React, Node.js). It combines e-commerce with short-form video discovery, creator monetization, in-stream shopping drawers, and real-time backend API integration.

---

## 🛠️ Technology Stack (100% Pure MERN)

* **MongoDB:** Mongoose ODM, MongoDB connection pool, Schema validators
* **Express.js:** REST API router (`/api/v1`), CORS, Helmet security, Morgan request logger, Error middleware
* **React:** React 18, Vite, Tailwind CSS, React Router v6, Lucide React, TanStack Query, Zustand
* **Node.js:** Node.js runtime environment

---

## ⚡ Quick Start & Development

### 1. Clone Repository & Install Dependencies
```bash
git clone https://github.com/rithesh2130-raja/palamner_palace.git
cd palamnerpalace
npm install
```

### 2. Environment Setup
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

### 3. Run Application
* **Backend Express API Server:** `http://localhost:5000`
* **Frontend React Application:** `http://localhost:5173`
* **Health API Endpoint:** `http://localhost:5000/api/v1/health`
