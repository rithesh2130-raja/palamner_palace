# Plmner Palace — Social-Commerce Marketplace

**Plmner Palace** is a full-stack social-commerce marketplace combining short-form video discovery (Reels), creator economy, affiliate attribution, and multimodal AI (Gemini Omni) product reel generation.

## 🚀 Key Features

* **Short-Form Video Reels Feed:** Centered 430px desktop frame (Spec #85), live runtime clock counter (`00:05 / 00:18`), and bottom seek progress bar.
* **In-Stream Product Drawers:** Inspect product details, choose variants, and add to cart without interrupting video playback.
* **Gemini Omni AI Reel Generator:** Synthesizes multimodal 9:16 video renders, captions, hashtags, and step-by-step AI voiceover storyboards.
* **Creator & Seller Studio:** Full creator monetization, 10-15% affiliate tracking, and seller promotion campaigns.
* **Full Stack Architecture:** Express, Node.js, MongoDB Mongoose, and React Vite.

## 📦 Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
npm run data:import
npm run server
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### 3. Access Application
* **Frontend Application:** `http://localhost:5173`
* **Backend API:** `http://localhost:5000`
